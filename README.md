# Hapyzo Technologies — hapyzo.com

Company website for **Hapyzo Technologies** (websites, apps, SaaS) plus the public **Speaklo** payment page for Razorpay.

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and [http://localhost:3000/speaklo](http://localhost:3000/speaklo).

## Razorpay payment link (optional)

Set in Vercel env (or `.env.local`):

```
NEXT_PUBLIC_RAZORPAY_PAYMENT_LINK=https://rzp.io/your-payment-link
```

When set, Speaklo CTAs open that Razorpay link.
